# C-Claw UI 重新设计

## 架构

方案 A：固定三栏布局，无 Vue Router，状态驱动面板切换。

```
┌──────┬──────────────────────┬──────────┐
│ 240px│        flex:1        │ 0→320px  │
│ 左侧 │       中间区域        │  右侧面板 │
│ 固定 │       动态切换        │  滑入滑出 │
└──────┴──────────────────────┴──────────┘
```

- 左侧栏：240px 固定宽度
- 中间区域：flex:1，v-if 切换视图（对话/会话列表/设置）
- 右侧面板：默认 0px，工具调用时滑入 320px，挤压中间区域
- 无 Vue Router

## 中间区域

三种视图通过 v-if 切换，统一深色主题：

1. **对话视图**（默认）：消息列表 + 输入框
2. **会话列表视图**：完整会话管理（搜索/删除/重命名）
3. **设置视图**：表单布局

---

## 右侧面板

- **触发**：工具调用时自动滑入（展开 320px）
- **关闭**：用户手动点击 X 关闭
- **内容**：工具调用轨迹（工具名、输入参数、执行结果、耗时）

---

## 对话气泡

- **布局**：左右分布，用户靠右（蓝色气泡），AI 靠左（深色气泡），均带头像
- **AI 回复**：
  - Thinking 内容：正文上方折叠区块（标题「思考过程」），流式输出时展开，完成后自动折叠，可点击展开回看
  - 正文：Markdown 渲染，代码块语法高亮
- **头像**：用户取昵称首字，AI 用固定图标

---

## 视觉风格

- **柔和暗色**：低饱和蓝紫调，柔和圆角，克制内敛
- **参考**：Claude 桌面客户端风格
- **颜色**：深色背景 + 低饱和蓝紫主色调 + 柔和圆角（8-12px）
- **字体**：系统默认（后续可替换为更精致的字体）
- **动效**：右侧面板滑入滑出、折叠区块展开/收起、视图切换淡入淡出

## 实现细节

### 会话标题异步生成
- 后端 `ClaudeService.generateTitle()`：非流式调用 Anthropic API，生成 3-8 词摘要
- 后端 `POST /api/sessions/{id}/generate-title`：取前 3 条用户消息，调用 GeminiService 生成标题
- 新会话创建时标题为 null，前端在消息发送完成后异步触发生成
- 失败静默降级，不影响主流程

### Skills 管理
- 后端 `GET /api/skills`：返回已安装 Skill 列表（name/version/description）
- 前端从 `~/.c-claw/skills/` 加载，支持空状态提示

### 数据导出
- 前端调用 `GET /api/sessions?limit=1000` 获取全部会话
- 浏览器端生成 JSON 文件并触发下载

### 更新检查
- 前端调用 GitHub Releases API 检查最新版本
- 非阻塞，失败静默降级
